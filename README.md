# Gowla V3.2 — Static Newsroom

نسخة ثابتة محسنة لموقع قناة جولة، جاهزة للنشر على Netlify.

## الجديد
- غرفة أخبار V3.2 متجاوبة للهاتف.
- إنشاء وتعديل وأرشفة الأخبار.
- رفع صورة الخبر من الهاتف عبر FileReader.
- بحث وتصفية الأخبار حسب الحالة والتصنيف.
- عاجل + خبر رئيسي.
- ربط الخبر بالمراسل.
- إدارة أولية للمراسلين.
- الصفحة الرئيسية تقرأ الأخبار من LocalStorage وتعرض الخبر الرئيسي والعاجل.
- نافذة قراءة الخبر داخل الموقع.
- لا تحتاج Database أو Identity في هذه المرحلة.

## مهم
البيانات محفوظة محليًا في المتصفح فقط. هذه نسخة معاينة/واجهة تشغيلية قبل ربط V4 بقاعدة بيانات وحسابات حقيقية.

## النشر
ارفع محتويات هذا المجلد إلى Netlify Drop عندما تكون عمليات Production Deploy متاحة في حسابك.
